# Archive — Molly's original analysis scripts

These are the original R scripts written by Molly for the LTH (long-term heating ×
wounding × *Acropora pulchra*) experiment, preserved here unmodified for
provenance and attribution. They are archive copies; do not run them for current
results.

They are **not** part of the reproducible pipeline (`code/_run_all.R`). The
current analysis in `code/01–21_*.R` was rebuilt from the raw data in
`data/raw/` and supersedes these for the manuscript. These scripts are kept as an
audit trail for the original variables, exploratory plots, and flagged samples.
Add the date the scripts were received/exported if that provenance becomes
important.
