Last checked: 2026-09-09

This note records the preliminary external Hauru colony information Molly forwarded on
2026-09-03 in the Gmail thread `Fwd: [EXTERNAL] A. Pulchra Moorea Follow-up`.
The forwarded message was from Trinity Conn to Molly on 2026-08-10.

## What The Email Adds

Trinity attached `hauru_colonies.xlsx`, a preliminary table of Hauru colonies from the
Ross Cunning / Trinity Conn work. The file includes:

- Hauru colony ID, such as `Apul-115`.
- Collection latitude and longitude, when available.
- Acute heat limit, reported as ED50. ED50 is the temperature where the
  photosynthesis-efficiency score drops halfway in an acute heat assay.
- Clonal group, meaning a genetic grouping from their whole-genome data.
- Dominant symbiont, meaning the main algal symbiont type detected.

Molly noted that the LTH source patch C coordinate looks close to Trinity/Ross
colony `Apul-115`. Trinity said exact identity would require calling SNPs from
our RNA sequencing (RNA-seq) data and comparing those SNPs to their whole-genome
data. SNPs are single DNA-letter differences.

Molly also noted in the 2026-09-03 LTH thread that Trinity/Ross have seen clones
from Hauru span different thickets and large distances, and that Trinity
mentioned a chromosomal inversion in four Hauru individuals at the AIMS meeting.
Those details make the same practical point: source-patch location is useful for
choosing candidate matches, but it is not enough to assign genetic identity or
acute heat-limit values.

Trinity also flagged the species name. Her current recommendation is to refer to
the Moorea animal as *Acropora cf. pulchra*, because the Moorea form appears not
to be the same as the Australian type specimen of *A. pulchra*. The existing
repo keeps historical filenames and project labels that use `apulchra` or
*A. pulchra*, but manuscript-facing text should carry this taxonomy caveat until
the author team settles final wording.

This supports using `Apul-115` as the first candidate to check against source

## Analysis Implication

The best next analysis is not to assign ED50 values to A, C, and D. Treat the
table as preliminary collaborator-provided context until the DNA-marker match is
done. The next analysis is to call host SNPs from the LTH RNA-seq reads and ask
Trinity or Ross to compare those SNPs against their whole-genome genotypes. The
comparison should also flag whether inversion structure or long-distance clone
structure affects the cluster labels.

If source patch C matches `Apul-115`, then C's chronic LTH resilience would be
paired with an acute ED50 of 36.380 C in the Trinity/Ross table. That value is
within the Hauru ED50 range, not the highest value in the table. So the
cross-method question is genuinely interesting: chronic heat-plus-wound
resilience may or may not rank the same coral backgrounds as an acute CBASS heat
limit.
