# Drive Method And Photo Provenance

Last audited: 2026-09-01

These files are local exports of Google Docs from the project Drive folder.
They are provenance material, not generated analysis outputs.

- `README_LTH_expression_by_temperature_2025.md`: project overview, design,
  response variables, and collection methods.
- `Experimental_Plan_Gene_Expression.md`: gene-expression experimental plan,
  biopsy plan, timeline, and RNA-seq hypotheses. This export includes the
  embedded biopsy-plan image from the Google Doc.
- `Experimental_Plan_Microscope_Photographs.txt`: separate microscope
  photography cohort, microscope settings, naming scheme, and scored traits.
- `Field_Notes_A_pulchra_healing_notes.txt`: day-by-day qualitative healing
  notes used to interpret the morphology trait columns.
- `Progress_Notes.txt`: meeting and analysis notes, including the 2026-09-01
  open decisions about pigmentation, healing versus regeneration, and genet
  effects.
- `sequencing-plan-keck-LTH.txt`: RNA-seq subset, plate-balance plan, and notes
  about days 1, 3, and 10.
- `LTH_Color_Card_Photos.txt`: NAS location for color-card photos.
- `LTH_Microscope_Characterization_Photos.txt`: NAS location for microscope
  characterization photos.
- `../nas_image_sources.md`: checked local NAS mount paths, SMB paths, and file
  counts for color-card and microscope image sources.

The image files themselves are not imported here because the Drive notes point
to `smb://stier-nas1.eemb.ucsb.edu`, not to files in the project Drive folder.
The resolved mounted NAS paths are recorded in
`docs/provenance/nas_image_sources.md`.
